    📖 数据格式说明 
    {
  "home": { "name": "家", "lat": 39.9, "lng": 116.4 },
  "places": [
    {
      "name": "东京",
      "lat": 35.68,
      "lng": 139.69,

      "country": "日本",

        {
          "date": "2024-11-22",
          "title": "红叶季之旅",
          "notes": "回忆备注",
          "photos": ["https://example.com/photo.jpg"]
        }
      ]
    }
  ]
}

    · name / lat / lng 必填，其余可选

    · status：visited 去过（默认）/ wishlist 想去

    · visits：每次旅行一条，日期用 YYYY-MM-DD

    💡 上面就是合法 JSON，可以直接复制当模板。电脑上也可以把 .json 文件拖到页面上导入。

    🧭 怎么玩

    💻 电脑（Windows）

    • ↑↓←→ 或 WASD 移动一家人
    • 回车 / 空格 打开附近的地点
    • Esc 关闭弹窗
    • ＋ － 或滚轮 缩放地图
    • L 地点列表 · F 回到一家人
    • 按住鼠标拖动可平移地图

    📱 iPhone / iPad

    • 左下角摇杆移动一家人
    • 点击地点图标，一家人会自动走过去并打开记录
    • 双指捏合缩放，单指拖动平移
    • 🎯 按钮回到一家人身边

    💡 走到一个去过的地方，它会亮起，全家会欢呼撒彩纸🎉，打开就能看到当时的旅行记录。虚线是按时间连起来的旅行路线。

    📂 右下角的 📂 按钮可以导入你自己的旅行数据文件（JSON）。数据只保存在本机浏览器里，不会上传到任何地方。
